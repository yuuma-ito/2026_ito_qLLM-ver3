# 失敗通知と詳細診断の比較実験結果

共通の初期失敗545組を比較した実験は完了しています。追加1回の主評価では、結果情報なしのR0が9.72%、失敗通知を加えたR1が10.83%、詳細診断も加えたR2が17.98%の成功率でした。

| --- | ---: | ---: |
| R0：結果情報なし | 53 / 545（9.72%） | 86 / 545（15.78%） |
| R1：失敗通知あり | 59 / 545（10.83%） | 93 / 545（17.06%） |
