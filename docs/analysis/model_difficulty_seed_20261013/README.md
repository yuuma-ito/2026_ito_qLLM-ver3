# モデル 難度 seed別の介入効果

検証済み3実験・5,000件の保存済み評価を層別集計した。全体のL3救出はF 191/582 (32.8%)、D 191/582 (32.8%)。モデル・難度・seedブロックの内訳を示す。統合値は混合手順の記述的結果であり、出典別集計を併記する。

R＝自己見直し、F＝実行結果提示、D＝自己デバッグ、P＝生成前注意事項。表の救出率の分母はbaselineのL3未達件数。部分改善はbaselineから段階が上昇したものの最終L3未達の件数。段階低下はbaselineから最終評価への比較であり、途中round間の一時的悪化やL3成功からの退行とは異なる。段階低下率の分母は全対応組数。Pは別プロンプトの独立生成としてCSVで区別する。

L2とL3救出はこのデータでは一致する。別の定義としてCSVに保存した。初期失敗0件の救出率は空欄。分母10件未満にはsmall_L3_failure_denominatorを付け、少数例の割合から優劣を断定しない。

## FとDが救出した例の重なり

初期未達582件のうち、両条件で救出149件、Fのみ42件、Dのみ42件、どちらでも未達349件だった。同じ救出数でも対象例がすべて一致するとは限らない。モデル・難度・seed・出典別の対応付き内訳はfeedback_debug_overlap.csvを参照。

## 次に確認する例

FとDの片方だけで救出した例を、baselineの失敗類型とタスクごとに確認する。部分改善が最終L3へ届かない理由、修正型の段階低下例も候補となる。追加実験の必要性は、元実験の処理差と少数分母を踏まえて判断する。
