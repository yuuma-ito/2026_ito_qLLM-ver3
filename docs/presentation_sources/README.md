# 発表資料の固定出典（presentation_sources）

| フォルダ | 内容 |
| --- | --- |
| [20261016T_reachable_rescues](20261016T_reachable_rescues/README.md) | 現行の中間発表・WiNF原稿の出典。救済経路、追加コスト、3回目修正の分析 |
| [20261013T_pooled_verified](20261013T_pooled_verified/README.md) | 旧評価による5,000件の統合集計を反映した固定出典 |
| [20261013T_levels_verified](20261013T_levels_verified/README.md) | 以前の到達段階分析に対応する固定出典 |
| [20261013_reach_levels](20261013_reach_levels/) | 3モデル本実験の到達段階集計 |

各時点のファイル構成・出典hash・検証範囲は配下の README とmanifestを確認します。更新されるレポートは [docs直下](../README.md)、編集用原稿は [midterm2026](../midterm2026/README.md) と [winf2026](../winf2026/README.md) にあります。
